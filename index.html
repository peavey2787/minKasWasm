Client

  1. Connect to a Kaspa node: 
    import { connect } from './wrapper/kaspa_client.js';

const client = await connect(rpcUrl, networkId, { onDisconnect });
    • rpcUrl: Node ip:port (or null for resolver)
    • networkId: e.g. "mainnet", "testnet-10"
    • onDisconnect: Optional callback for disconnect events

Wallet Management

  1. Initialize the wallet: 
    import { init } from './wrapper/wallet_service.js';

init({ rpcClient: client, networkId, balanceElementId, onBalanceChange });
    • rpcClient: The connected Kaspa client
    • networkId: Network string
    • balanceElementId: (optional) DOM element ID to update balance
    • onBalanceChange: (optional) callback for balance updates
  2. Create/Import a wallet: 
    import { createWallet } from './wrapper/wallet_service.js';

const { mnemonic, address } = await createWallet({
  password,           // Wallet password
  filename,           // (optional) Wallet filename
  userHint,           // (optional) User hint for wallet
  mnemonic,           // (optional) Import mnemonic
  storeMnemonic       // (optional) Store mnemonic in storage
});
    • password: Wallet password
    • filename: (optional) Wallet filename
    • userHint: (optional) User hint for wallet
    • mnemonic: (optional) Import mnemonic
    • storeMnemonic: (optional) Store mnemonic in storage
  3. Send Kaspa: 
    import { send } from './wrapper/wallet_service.js';

await send({
  amount,            // Amount in KAS
  toAddress,         // Destination address
  payload,           // (optional) Payload string
  priorityFeeKas     // (optional) Extra priority fee in KAS
});
    • amount: Amount in KAS
    • toAddress: Destination address
    • payload: (optional) Payload string
    • priorityFeeKas: (optional) Extra priority fee in KAS
  4. Other wallet functions: 
    import { getSpendableBalance, generateNewAddress, generateNewKeypair } from './wrapper/wallet_service.js';

const balance = await getSpendableBalance();
const address = await generateNewAddress(); // generateNewAddress(change = false)
const keypair = await generateNewKeypair(index); // index: child key index (number)
    • generateNewAddress(change): change (optional, default false) - if true, generates a change address
    • generateNewKeypair(index): index (number) - child key index

Wallet File Management

  1. Get a list of all wallets: 
    import { getAllWallets } from './wrapper/wallet_service.js';

const wallets = await getAllWallets();
// wallets: Array of { filename, title, ... }
    • getAllWallets(): Returns array of wallet file info objects
  2. Delete a wallet by filename: 
    import { deleteWalletData } from './wrapper/storage.js';

await deleteWalletData(filename); // filename: string
    • deleteWalletData(filename): Deletes wallet by filename from storage

Block Scanner

  1. Block Scanner usage: 
    import { KaspaBlockScanner, SearchMode } from './wrapper/scanner.js';

const scanner = new KaspaBlockScanner(client); // client: connected Kaspa RPC client
scanner.setSearch(searchString, SearchMode.INCLUDES); // searchString: string to search, mode: 'includes' or 'startsWith'
await scanner.start((block, match, matchedPayload) => {
  // block: block object
  // match: true if payload matched
  // matchedPayload: decoded payload string (if matched)
});
scanner.stop();
    • setSearch(searchString, mode): searchString (string), mode (optional, 'includes' or 'startsWith')
    • start(onBlock): onBlock (function) - callback for each block
    • stop(): Stops the scanner

RPC Commands

  1. Run arbitrary RPC commands: 
    import { runRpcCommand } from './wrapper/rpc_runner.js';

const result = await runRpcCommand(client, '{"method":"getInfo","params":{}}');
// client: connected Kaspa RPC client
// cmdText: JSON string with { method, params }
    • client: connected Kaspa RPC client
    • cmdText: JSON string with { method, params }

Encryption

  1. Symmetric Encryption usage: 
    import { encryptMessage, decryptMessage } from './wrapper/encryption.js';

// Encrypt
const encrypted = encryptMessage(plaintext, password); // plaintext: string, password: string

// Decrypt
const decrypted = decryptMessage(encrypted, password); // encrypted: object/string, password: string
    • encryptMessage(plaintext, password): plaintext (string), password (string)
    • decryptMessage(encrypted, password): encrypted (object/string), password (string)
  2. Diffie–Hellman Encryption usage: 
    import { DHSession } from './wrapper/dh_encryption.js';

const dh = new DHSession();
// Initiate handshake
const handshakeMsg = dh.initiateHandshake(myPrivateKey, myPublicKey); // myPrivateKey: hex string, myPublicKey: hex string
// Respond to handshake
const response = await dh.respondToHandshake(peerPublicKeyHex); // peerPublicKeyHex: hex string
// Encrypt
const encrypted = dh.encrypt(message); // message: string
// Decrypt
const decrypted = dh.decrypt(encrypted); // encrypted: object/string
    • initiateHandshake(myPrivateKey, myPublicKey): myPrivateKey (hex string), myPublicKey (hex string)
    • respondToHandshake(peerPublicKeyHex): peerPublicKeyHex (hex string)
    • encrypt(message): message (string)
    • decrypt(encrypted): encrypted (object/string)
